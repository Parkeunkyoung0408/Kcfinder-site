FLOSS GUIDE

HOW TO FLOSS

How to Floss

  1. Use approximately 16-18 in / 40-45 cm of floss.

  2. Gently guide the floss between teeth.

  3. Curve the floss into a C-shape around each tooth.

  4. Gently clean beneath the gumline.

  5. Use a fresh section of floss for each tooth.
