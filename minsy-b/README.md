# MINSY B안

index.html을 열면 B안을 볼 수 있습니다. A안은 수정하지 않았습니다.

기존 문구, 제품 이미지, 사용 전후 비교, 제품 선택, 구매 안내를 유지했습니다.
민트·로즈 제품 배경, 중앙 정렬된 섹션 제목, 간결한 헤더와 여백으로 레이아웃을 변경했습니다.

참고:
- https://www.lapa.ninja/post/lasso/
- https://dribbble.com/shots/27821507-DTC-supplement-website-design-Wellness-ecommerce-website-design

이 채팅에서는 브라우저 접근이 불가능하여 실제 렌더링 검수는 미완료입니다.
